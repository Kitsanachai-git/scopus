01 / KNN

K-Nearest Neighbor (KNN)

Instance-Based Learning (Lazy Learning) ที่ไม่สร้างแบบจำลองล่วงหน้า แต่เก็บข้อมูลฝึกทั้งหมดไว้ แล้วเปรียบเทียบข้อมูลใหม่กับข้อมูลที่เก็บไว้ตอนทำนายผล บนหลักการที่ว่า “สิ่งที่คล้ายกันมักอยู่ใกล้กัน”

Theory

  • ประเภทการเรียนรู้: Instance-Based / Lazy Learning — ไม่มีขั้นตอนฝึกโมเดล ใช้ข้อมูลฝึกทั้งหมดตอนทำนายเลย
  • ใช้ได้กับ: Classification และ Regression
  • กระบวนการ: รับข้อมูลใหม่ → คำนวณระยะห่างกับทุกจุด → เรียงลำดับระยะทาง → เลือก k จุดที่ใกล้ที่สุด → โหวตเสียงข้างมาก (Majority Vote) → ทำนายผล
  • ระยะทางที่นิยม: Euclidean, Manhattan, Minkowski Distance
  • ค่า k ขนาดเล็ก: ยืดหยุ่นสูง (Flexible) แต่ไวต่อ Noise
  • ค่า k ขนาดใหญ่: เสถียร (Stable) แต่เสี่ยง Underfitting
  • ข้อจำกัด: ใช้หน่วยความจำมาก ทำนายช้าเมื่อข้อมูลเยอะ และประสิทธิภาพลดลงเมื่อมิติข้อมูลสูง (Curse of Dimensionality)
Euclidean Distance d(A, B) = √[(x₁ − x₂)² + (y₁ − y₂)²]

02 / KNN Regression

KNN Regression

อัลกอริทึมเดียวกับ KNN แต่ใช้พยากรณ์ค่าตัวเลขแทนการจำแนกประเภท โดยค่าที่ทำนายมาจากค่าเฉลี่ย หรือค่าเฉลี่ยถ่วงน้ำหนัก (Weighted Average) ของค่าเป้าหมายของเพื่อนบ้าน k ตัว

Theory

  • ขั้นตอน: กำหนด k → คำนวณระยะห่างข้อมูลใหม่กับข้อมูลฝึกทุกตัว → เรียงจากน้อยไปมาก → เลือก k ตัวที่ใกล้สุด → เฉลี่ยค่า Target
  • Plain KNN Regression: ใช้ค่าเฉลี่ยธรรมดาของเพื่อนบ้าน k ตัว
  • Weighted KNN Regression: ให้น้ำหนักตามระยะทาง — จุดที่ใกล้กว่ามีอิทธิพลต่อคำตอบมากกว่า
  • การใช้งาน: พยากรณ์ราคาบ้าน ราคาหุ้น อุณหภูมิ คะแนนสอบ การใช้พลังงานไฟฟ้า
Plain averageŷ = ( Σ yᵢ , i=1..k ) / k Weighted averageŷ = Σ(wᵢ·yᵢ) / Σ wᵢ ,   wᵢ = 1 / (d(x,xᵢ)ᵖ + ε)

03 / K-Means

K-Means Clustering

Unsupervised + Instance-Based Learning ที่จัดกลุ่มข้อมูลออกเป็น K กลุ่มโดยไม่ต้องมีป้ายกำกับ (Label) อาศัยระยะห่างระหว่างจุดข้อมูลกับจุดศูนย์กลางกลุ่ม (Centroid) เป็นเกณฑ์การจัดกลุ่ม

Theory

  • ประเภท: Partitioning Algorithm — แบ่งข้อมูลออกเป็น K กลุ่มตามความใกล้เคียงกับ Centroid
  • ขั้นตอนที่ 1: กำหนดจำนวนกลุ่ม K
  • ขั้นตอนที่ 2: กำหนดจุดศูนย์กลางเริ่มต้น (Initial Centroids)
  • ขั้นตอนที่ 3: Cluster Assignment — คำนวณระยะห่างแต่ละจุดกับ Centroid แล้วจัดเข้ากลุ่มที่ใกล้ที่สุด
  • ขั้นตอนที่ 4: Update Centroid — หาค่าเฉลี่ยของจุดในแต่ละกลุ่มเป็น Centroid ใหม่
  • ขั้นตอนที่ 5: ทำซ้ำขั้นตอน 3–4 จนกว่า Centroid จะไม่เปลี่ยนแปลง หรือครบจำนวนรอบที่กำหนด
  • จุดเด่น: ไม่ต้องใช้ข้อมูลมี Label ทำงานเร็ว เข้าใจง่าย เหมาะกับ Exploratory Data Analysis
  • การใช้งาน: แบ่งกลุ่มลูกค้า จัดกลุ่มนักเรียนตามผลการเรียน จัดกลุ่มข่าว/เอกสาร/รูปภาพ
